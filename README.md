# Анализатор HTML-документов

Консольная программа на C++ для разбора HTML-файлов и проверки вложенности тегов.

## Возможности

- Выбор файлов с расширением `.html` или `.htm` из каталога `SourceTexts`.
- Разбор тегов, атрибутов, комментариев, деклараций и текстовых фрагментов.
- Проверка парных тегов с помощью стека.
- Вывод найденных ошибок с указанием строки и столбца.
- Подсчёт основных элементов документа.

## Сборка

1. Откройте `TRPO_indivisualnoe_zadanie.sln` в Visual Studio.
2. Выберите конфигурацию Debug или Release и платформу x64.
3. Соберите решение. Для проекта используется C++17.

## Запуск

Положите HTML-файлы в каталог `SourceTexts` и запустите программу. Если запускаете из Visual Studio, рабочим каталогом решения должен быть каталог, в котором находится `SourceTexts`.

В главном меню выберите пункт проверки файла, затем укажите его номер в списке.

## Принятые ограничения

Программа проверяет структуру тегов в поддерживаемом подмножестве HTML. Она не заменяет полноценный HTML5-валидатор и не строит DOM.

- Обычные открывающие теги должны иметь явный закрывающий тег.
- Правила HTML5 для необязательных закрывающих тегов не применяются.
- Специальная обработка содержимого элементов `script` и `style` не реализована.
- Значения атрибутов могут быть заключены в одинарные или двойные кавычки либо записаны без кавычек.
- При чтении удаляется UTF-8 BOM, если он присутствует.

## Проверка

Для ручной проверки в `SourceTexts` есть два примера: `example_valid.html` и `example_errors.html`. При проверке также стоит попробовать пустой файл, незакрытый комментарий, лишний закрывающий тег и неверный порядок вложенности.
