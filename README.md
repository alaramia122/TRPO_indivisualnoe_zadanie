# Анализатор HTML-документов

Консольная учебная программа на C++ для ручного разбора HTML и проверки структуры тегов.

## Состояние реализации

- Подготовлена процедурная структура модулей в стиле Kursovaya_PYAVU.
- Реализованы выбор и чтение файлов .html и .htm из каталога SourceTexts.
- Реализован ручной разбор тегов, атрибутов, комментариев и текста.
- Реализована проверка парных тегов стеком и вывод диагностик.
- Добавлены примеры входных файлов для ручной проверки.

## Сборка

Откройте решение Visual Studio и соберите проект с C++17. Проект рассчитан на Windows Console API и стандартную библиотеку C++.

## Запуск

Поместите документы в каталог SourceTexts рядом с рабочим каталогом приложения. В главном меню выберите проверку HTML-файла.

## Ограничения первой реализации

- Реализуется поддерживаемое подмножество HTML, а не полная проверка соответствия HTML5.
- Правила восстановления DOM, необязательные закрывающие теги и специальные raw-text-правила script/style пока не реализованы.
- Предполагается кодировка UTF-8; UTF-8 BOM удаляется при чтении.
- Проверка выполняется вручную по тест-кейсам проектного документа.
- utils.cpp и utils.h скопированы из исходного Kursovaya_PYAVU; контрольные суммы нужно сверить перед релизом.
