# Анализатор HTML-документов

Консольная учебная программа на C++ для ручного разбора HTML и проверки структуры тегов.

Проект реализуется в процедурном стиле, близком к `Kursovaya_PYAVU`. Существующие `utils.cpp` и `utils.h` используются без изменения содержимого.

Статус: начальная настройка репозитория; детали сборки и поддерживаемое подмножество HTML будут уточнены по мере реализации.
