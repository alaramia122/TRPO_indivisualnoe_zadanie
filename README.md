# Анализатор HTML-документов

Консольная программа на C++ для разбора локальных HTML-файлов, извлечения основных сведений о странице и проверки структуры тегов.

## Возможности

- Выбор HTML-файла с расширением `.html` или `.htm` из каталога `SourceTexts`.
- Разбор тегов, атрибутов, текстовых фрагментов, комментариев и деклараций.
- Проверка вложенности тегов с использованием стека и вывод диагностик с указанием строки и столбца.
- Подсчёт открывающих, закрывающих и самозакрывающихся тегов, атрибутов, комментариев, текстовых фрагментов и найденных диагностик.
- Извлечение сведений из документа:
  - названия страницы из `title`;
  - выбранных метаданных, включая `description`, `keywords`, `author`, `application-name` и свойства Open Graph;
  - заголовков `h1`–`h6`;
  - текстовых фрагментов страницы;
  - ссылок с подписями и адресами;
  - изображений с альтернативным текстом и адресом;
  - атрибутов элементов управления форм;
  - канонического URL.
- Просмотр результатов по разделам с помощью клавиш-стрелок.
- Сохранение статистики, извлечённых сведений и диагностик в текстовый отчёт в кодировке UTF-8.

## Требования

- Windows.
- Visual Studio с поддержкой C++.
- Стандарт языка C++17.

Программа использует Windows API для работы с кодировками и функции управления консолью Windows.

## Сборка

1. Откройте файл `TRPO_indivisualnoe_zadanie.sln` в Visual Studio.
2. Выберите конфигурацию `Debug` или `Release` и платформу `x64`.
3. Выполните сборку решения средствами Visual Studio.

## Запуск

1. Поместите файлы для анализа в каталог `SourceTexts`.
2. Запустите собранную программу. При запуске из Visual Studio укажите в качестве рабочего каталога папку, в которой находится `SourceTexts`.
3. В главном меню выберите проверку файла и укажите его номер в списке.
4. Просмотрите статистику, найденные сведения и диагностики.
5. После просмотра выберите, нужно ли сохранять результат.

Для навигации по результатам используются клавиши-стрелки:

- **Вверх / Вниз** — переключение раздела.
- **Влево / Вправо** — переключение значения в выбранном разделе.
- **Enter / Esc** — завершение просмотра и переход к предложению сохранить отчёт.

## Результаты анализа

При сохранении программа создаёт каталог `AnalysisResults`, если он отсутствует, и записывает отчёт в файл с именем на основе исходного файла, например `example_valid_analysis.txt`. Если такой файл уже существует, к имени добавляется числовой суффикс; существующие отчёты не перезаписываются.

В отчёт входят статистика, извлечённые сведения по разделам и диагностики с координатами обнаруженных проблем.

## Ограничения

- Анализ выполняется локально по содержимому выбранного файла. Программа не загружает страницы из интернета и не выполняет JavaScript.
- Проверяется поддерживаемое подмножество структуры HTML. Программа не реализует полный алгоритм построения DOM и не заменяет HTML5-валидатор.
- Для обычных парных тегов ожидается явный закрывающий тег. Правила HTML5 для необязательных закрывающих тегов не применяются.
- Содержимое элементов `script` и `style` исключается из извлечённого текста страницы.
- Значения атрибутов могут быть заключены в одинарные или двойные кавычки либо записаны без кавычек.
- При чтении удаляется BOM в начале UTF-8-файла, если он присутствует. Поддержка произвольных кодировок и автоматическое определение кодировки не гарантируются.
- Из метаданных извлекается заданный набор полей; остальные метаданные могут не попасть в результат.
- Извлечение текста выполняется по токенам разметки и не воспроизводит визуальное отображение страницы в браузере.

## Ручная проверка

В каталоге `SourceTexts` предусмотрены примеры:

- `example_valid.html` — корректная структура в пределах поддерживаемых правил;
- `example_errors.html` — разметка с ошибками для проверки диагностик.

Дополнительно проверьте поведение на пустом файле, незакрытом комментарии, лишнем закрывающем теге, неверном порядке вложенности и файле с BOM в начале UTF-8-текста.
